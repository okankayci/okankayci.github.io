# Design System: Apple Design Language (HIG)

## Overview
PixelFlow Studio'nun bu görsel dünyası, Apple'ın Human Interface Guidelines ve Apple.com ürün tanıtım zarafeti üzerine inşa edilmiştir. Ferah negatif alanlar, Apple'ın ikonik gri tonları, yarı saydam buzlu cam (frosted glass) gezinme çubuğu, sürekli kavisli squircle uygulama ikonları ve Keynote tarzı Bento ızgarasıyla şekillenmiştir.

## Colors
- **Light Theme (Apple Studio Canvas):**
  - Tuval: `#f5f5f7` (Apple'ın ikonik yumuşak açık gri zemin rengi)
  - Yüzey / Kartlar: `#ffffff` (Saf beyaz, pürüzsüz kartlar)
  - Tipografi: `#1d1d1f` (Apple derin grafit siyahı)
  - İkincil Metin: `#86868b` (Apple gri)
  - Vurgu: `#0071e3` (Apple Signature Blue)
  - Sınırlar: `rgba(0, 0, 0, 0.08)` (Kılcal Apple sınırları)
- **Dark Theme (Apple OLED Pro Canvas):**
  - Tuval: `#000000` (Apple saf OLED siyahı)
  - Yüzey / Kartlar: `#1d1d1f` (Apple Space Gray)
  - Tipografi: `#f5f5f7`
  - İkincil Metin: `#86868b`
  - Vurgu: `#2997ff` (Apple Pro Blue)
  - Sınırlar: `rgba(255, 255, 255, 0.12)`

## Typography
- **Font Ailesi:** `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", sans-serif`
- **Başlık Hiyerarşisi:**
  - Hero Display: `clamp(2.75rem, 5.5vw, 4.5rem)`, `-0.035em` harf aralığı, `1.06` satır yüksekliği.
  - Headline: `clamp(2rem, 3.8vw, 2.75rem)`, `-0.03em`.
  - Hero Lead: `clamp(1.1rem, 2vw, 1.35rem)`, `1.45` satır yüksekliği.

## Layout
- **Genişlik & Ritim:** Maksimum konteyner `1120px` (%90 genişlik).
- **Merkezi Keynote Hero:** Ortalanmış büyük başlık, ferah nefes alanı, Apple hap butonlar ve altında 2 sütunlu interaktif donanım vitrini.
- **Bento Felsefe Izgarası:** 3 sütunlu bağımsız kartlar ve geniş taban kartı.

## Elevation & Depth
- Yapay renkli neon halkaları yerine, Apple'ın gerçek ışık kırılımını yansıtan yumuşak katman gölgeleri:
  - `--shadow`: `0 4px 12px rgba(0, 0, 0, 0.06)`
  - `--shadow-xl`: `0 24px 60px rgba(0, 0, 0, 0.12)` (Açık mod) / `0 24px 64px rgba(0, 0, 0, 0.8)` (Koyu mod)

## Components
- **Frosted Glass Header:** `background: rgba(245, 245, 247, 0.8); backdrop-filter: saturate(180%) blur(20px);`
- **Segmented Control:** Apple'ın hap kapsül filtre ve sekme çubuğu.
- **Squircle İkonlar:** `border-radius: 13px - 14px` (Apple'ın %22.37 kavis kuralı).
- **Apple Pill Butonlar:** Tam yuvarlak (`border-radius: 9999px`) mavi ve şeffaf butonlar.
